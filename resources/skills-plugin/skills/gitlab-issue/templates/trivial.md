# trivialテンプレート

typo修正、設定値1つの変更、依存バージョン更新など、説明が要らない変更に使う。

**変更が1ファイル数行に収まり、技術判断もリスクも無い**場合に限る。迷ったら `chore` を使う。

以下をコピーして埋める。

```markdown
**種別**: trivial

## 概要

**現状**: (変更前の値・状態。1行)

**開始日**: YYYY-MM-DD (着手予定日。起票時に埋める)

**何が変わるか**: (1行)

## 詳細

### 実装計画

- [ ] (1タスクで済む場合も1項目書く)

## 確認点

### 受入基準

- [ ] (検証可能な1〜2項目)
  - 検証: `<コマンド>`
  - 期待: (出力・状態)

## 実装後追記

(実装後に記載。trivialでは試行錯誤の記録を省略してよい)
```
