## 共通の注意点

simulateWebviewMessageはホスト側ハンドラへ直接入力する。レンダラーのイベント結線、HTML表示、1クリックからpostMessageまでを保証しない。フェイクでCLIが応答を返すテストと実CLI互換性を区別する。

多くのteardownはstopとremoveWorktreesを呼ぶが返されたfailed配列をassertせず、失敗すると後続の差替え解除へ進まない。疑似worktreeでは同期rmの前に非同期停止完了を待たない。fixture全体の隔離は別の起動ガードに依存する。ここにあるgit commit・push・削除処理は読んだだけで実行していない。
