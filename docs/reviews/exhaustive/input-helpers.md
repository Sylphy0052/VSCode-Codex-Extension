## EX-TEST-04[P2]:重複排除のテストに重複入力がない

[test/unit/commandCatalog.test.ts:95](../../../test/unit/commandCatalog.test.ts#L95)は「同じ名前は後から見つけたものを捨てる」としてdaily-reportの件数を1と比較する。しかしfixtureにdaily-reportは1件しかなく、重複を捨てる処理を取り除いても成功する。homeとworkspaceなどに同名かつ内容の異なる候補を置き、残る件数と先勝ちの内容を確認する必要がある。

同ファイルの「読めないディレクトリでも落ちない」も、列挙が空配列を返すだけでエラーを作らない。空の結果にeveryを適用するため期待値が無条件で成立する。これは異常系の検証不足として記録し、製品の新規不具合とは数えない。
