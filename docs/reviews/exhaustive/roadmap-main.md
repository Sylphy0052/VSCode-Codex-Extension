## EX-ROADMAP-01[P2]:文字列のIssue番号が削除されない

`roadmap.ts:781`はrawIssueが数値以外ならundefinedとし、元の項目にもIssueがなければ「一致」として削除を飛ばす。`issue: '12'`は`workflow.ts:380`以降で有効な12として読み込まれるため、番号が残る。`extension.ts:2291`以降は不一致を警告するだけで保存を止めず、`forge.ts:384`のClosesへ届く。必要なのは元項目に番号がない場合のフィールド自体の削除と、quoted/unquoted両方の試験。現行削除試験は数値だけ。

## EX-ROADMAP-02[P2]:受け付ける箇条書き記号を書戻しで扱えない

解析は`* [ ] R1 ...`と`+ [ ] R1 ...`を項目として受け付けるが、`roadmap.ts:909`の置換正規表現は`-`限定。doneになっても986行の置換が変化せず、updatedItemIdsも空のまま未完了表示が残る。読取りの*と+の試験はあるが、書戻し試験は全て-。共通の記号集合を使い、3種類全ての読取り→更新を確認する必要がある。

## EX-ROADMAP-03[P1]:外部へのリンクを辿ってロードマップを書き込む
