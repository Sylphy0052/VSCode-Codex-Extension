| 対象                                              | 確認内容と不足                                                                                                                                                                                                                                                                                             |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| isValidMcpServerNameと共有型                      | stringと正規表現、先頭英数字・後続の英数字/_.-、snapshot成功/失敗とserver状態を確認。3テストは通常3名、空/空白/先頭dot/slash、型不正。ドットを許すためkeyPathが変わる問題は既存F16-01を参照                                                                                                                |
| isValidSkillPathと共有型                          | stringかつ/始まりの判定、origin/toggleable/識別key等の契約を確認。3テストはPOSIX絶対・相対/空・型不正。Windowsのドライブ絶対パスは拒否する。書込入口と画面の確認は[control-panel-main.md](control-panel-main.md)を参照                                                                                     |
| mcpDisableのrecord/buildDisabledMcpServersOverlay | 入れ子configの構造確認、組込名とObject.keysのSet結合、全名へのdisabled+dummy commandを確認。3テストは既定+設定名の完全一致、非空、不正構造5種。JSON由来の__proto__という名前では普通のobjectへの代入がown keyにならず、無効化対象から欠落する。実際のCLIで許容される名前かは未確認なので契約上の注意とする |
| parseMcpServerStatusList                          | data配列、各entryの非空名、serverInfo object有無、tools数、version、Map重複名上書きを確認                                                                                                                                                                                                                  |
| parseConfigMcpServersEnabled                      | configの3段rec、欠落の空Map、各valueのenabled=falseだけ無効として扱う分岐を確認                                                                                                                                                                                                                            |
| mergeMcpServers                                   | 名前の和集合、無効優先、接続済み、接続不可、名前sort。disabled/unavailableのtoolCount=0・versionなし・reasonなしを確認                                                                                                                                                                                     |
| str/strOrUndefined/rec                            | 型不正の空文字、空文字のundefined、object/null/arrayを確認                                                                                                                                                                                                                                                 |
