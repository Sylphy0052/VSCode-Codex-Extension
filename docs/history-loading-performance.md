# 履歴読み込みの高速化

## 目的

起動直後に履歴ツリーを表示し、履歴ファイル数に比例する走査をユーザー操作の待ち時間から外す。

## 受入基準

- Claude Codeの履歴は前回保存した一覧があれば、全transcriptを走査せずに表示する。
- 起動後にバックグラウンドで全transcriptと照合し、結果が変われば履歴ツリーを更新する。
- 起動後のtranscript変更は変更対象だけを再読込し、全走査を行わない。
- Codex app-serverの`thread/list`が失敗した場合、短時間の連続更新で同じロールアウト全走査を繰り返さない。
- CodexとClaude Codeの一覧取得は並列に実行する。
- 起動時のメタキャッシュ掃除は初回の履歴表示と同時にディスク走査しない。
